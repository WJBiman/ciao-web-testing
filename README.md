## 🌟 Executive Summary

**CIAO (Pvt) Ltd** is a state-of-the-art, multi-tenant digital transit hub engineered to modernize Sri Lanka’s inter-provincial passenger and logistics network. Designed in strict alignment with university curricular requirements and enterprise software architecture standards, CIAO provides:

1. **Passenger Experience:** High-speed route discovery, interactive **2D visual seat maps**, 10-minute temporary seat reservation holds with concurrency safety, and cryptographically verified **QR Code e-tickets**.
2. **Parcel Express Logistics:** Real-time branch-to-branch package consignment, server-calculated weight pricing, and doorstep-to-terminal milestone tracking.
3. **Group Charter Hire:** End-to-end bus chartering with automated fleet availability verification and advance split-deposit management.
4. **Operations & Fleet Command:** Complete route and tariff administration, driver scheduling, real-time bus inspection, lost-and-found property arbitration, and executive financial auditing.

```
                          ┌─────────────────────────────────────┐
                          │     Next.js 16.3 Web Frontend       │
                          │  (App Router, React 19, TypeScript) │
                          └──────────────────┬──────────────────┘
                                             │ HTTP / REST / Cookie JWT
                                             ▼
                          ┌─────────────────────────────────────┐
                          │      Spring Boot 3.2.5 Backend      │
                          │  (Spring Security 6, Stateless JWT) │
                          └──────────────────┬──────────────────┘
                                             │ Spring Data JPA / Hibernate
                                             ▼
                          ┌─────────────────────────────────────┐
                          │        MySQL 8.0+ Database          │
                          │      (17 EER Relational Tables)     │
                          └─────────────────────────────────────┘
```

### 💻 Backend Engineering
* **Language & Framework:** Java 17 (OpenJDK / Oracle JDK) • Spring Boot 3.2.5
* **Security & Auth:** Spring Security 6 with HMAC-SHA256 JWT, HttpOnly cookie transmission, and role-based ACLs
* **Concurrency Control:** Pessimistic row locking on temporary seat allocations (`SELECT ... FOR UPDATE`)
* **Persistence & ORM:** Spring Data JPA with Hibernate 6, HikariCP connection pooling
* **Verification:** JUnit 5, Mockito, Spring Boot Test, H2 In-Memory Database (87 automated unit/integration tests)

### 🎨 Frontend & Design System
* **Core Framework:** Next.js 16.3 with Turbopack, App Router, React 19
* **Typography & Palette:** Custom Luxury UI Tokens (`#0B1220` Deep Navy, `#193542` Midnight Slate, `#087478` Teal Accent, `#F4C95D` Gold Highlight)
* **Visual Experience:** Lucide React Iconography, Framer Motion transitions, real-time reactive seat grid

## 🚀 Quick Start Guide

### 1. Prerequisites
* **Java Development Kit (JDK):** Version 17+ (`java -version`)
* **Node.js:** Version 18.x or 20.x+ (`node -v`)
* **Database Server:** MySQL Server 8.0+ or MariaDB 10.4+ (XAMPP supported on port `3306`)
* **Build Tool:** Apache Maven 3.9+ (or use the included Maven wrapper)

---

### 2. Database Initialization
Start your local MySQL service (e.g. through the XAMPP Control Panel) and import the master schema:

```bash
mysql -u root -p < schema.sql
```
> *Note: If your local MySQL `root` user does not have a password (default XAMPP setup), simply press **Enter** when prompted.*

The `schema.sql` automatically creates all **17 relational tables** and pre-provisions complete seed data:
* 5 Provincial Terminal Branches (Colombo, Kandy, Galle, Matara, Jaffna)
* 4 Active Buses with 42-seat layouts & verified drivers
* Inter-city routes with expressway interchanges and recurring daily schedules
* Pre-configured staff, management, and passenger demo accounts

---

### 3. Backend Setup & Run

```bash
# Navigate to the backend directory
cd backend

# Run the complete test suite (87 tests)
mvn clean test

# Package and launch the Spring Boot API
mvn clean package -DskipTests
java -jar target/backend-0.0.1-SNAPSHOT.jar
```
The backend server starts listening at **`http://localhost:8080`**.

---

### 4. Frontend Setup & Run

```bash
# Navigate to the frontend directory
cd frontend

# Install package dependencies
npm install

# Launch the Next.js development server
npm run dev
```
Open **`http://localhost:3000`** in your browser to experience the application.

---

### 5. One-Command Automated Launch (Windows)
A unified PowerShell script orchestrates MySQL, Spring Boot, and Next.js in parallel:
```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start-local.ps1
```
Or double-click **[`start-local.cmd`](start-local.cmd)** from the repository root.

## 🧭 Key Application Endpoints

### 🌐 Passenger Web Portal (`http://localhost:3000`)
* `/` — Inter-city bus route explorer, schedule search, dynamic tariff lookup
* `/select-seats?scheduleId=1` — Interactive 2D seat map with live availability
* `/checkout-payment` — Simulated payment checkout with instant QR e-ticket issuance
* `/my-bookings` — Customer booking history with cancellation request initiation
* `/book-parcel` — Branch-to-branch parcel consignment intake with weight calculator
* `/track-parcel` — Real-time consignment milestone progression
* `/group-booking` — Private group bus chartering application

### 🛡️ Management & Staff Portal (`http://localhost:3000/management`)
* `/dashboard` — Master operations cockpit with active bookings and fleet status
* `/routes` — Provincial route creation, sequence ordering, distance adjustment
* `/fleet` — Bus inventory, seat configuration, driver license verification
* `/parcels` — Branch consignment manifests and status updates
* `/group-bookings` — Charter review, advance deposit approval, conflict checks
* `/lost-and-found` — Item intake, claimant verification, resolution audit
* `/conductor` — Mobile-ready camera QR code check-in scanner for conductors
